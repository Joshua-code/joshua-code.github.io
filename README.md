# joshua-code.github.io

The root of Joshua's GitHub Pages domain. It exists to serve
[`app-ads.txt`](https://joshua-code.github.io/app-ads.txt) for the AdMob
account behind the Android app Recording Kandang (`com.recording.kandang`),
whose Play listing names `https://joshua-code.github.io/...` as its website.

The app's own pages (privacy policy, account deletion) are in
[`recording-kandang-site`](https://github.com/Joshua-code/recording-kandang-site).
